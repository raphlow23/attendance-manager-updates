출근정리 설치 안내 (2026-10-29-r55)

검증 상태
- 소스 수정과 오프라인 테스트를 완료한 버전입니다.
- 첨부된 화면을 기준으로 근태 표/수정 입력칸을 인식하도록 구현했습니다.
- 실제 사이트에 로그인하여 수정·저장하는 통합 테스트는 아직 하지 않았습니다.
- 화면 구조가 다르거나 날짜/입력칸이 명확하지 않으면 수정하지 않고 로그에 남깁니다.

비용 및 실행 방식
- 서버나 유료 호스팅을 사용하지 않습니다.
- Windows PC에서 실행하므로 이 프로그램에 별도 서버 이용료가 없습니다.
- PC가 꺼진 동안에는 실행하지 않습니다. 놓친 퇴근은 다음 출근 때 보완합니다.

기존 자동 실행
- 평일 출근: 08:30~08:55, 5분 단위 무작위.
- 일반 퇴근: 18:05~18:55, 5분 단위 무작위.
- 주말과 대한민국 공휴일은 실행하지 않습니다.
- PC가 계속 켜져 있고 Windows에 로그인되어 있으면 기존 예약 출퇴근을 유지합니다.
- 자동 절전/로그아웃 상태에서는 예약을 놓칠 수 있습니다.

월 연장 설정
- 초기 관리 화면에서 월 연장시간과 하루 기준(1시간 또는 2시간)을 선택합니다.
- 연장일 수 = 월 연장시간 ÷ 하루 기준.
- 월 10시간 + 하루 1시간 = 월 10일, 퇴근 19:00~19:55.
- 월 10시간 + 하루 2시간 = 월 5일, 퇴근 20:00~20:55.
- 기본 5분 단위이며 1분 간격도 선택할 수 있습니다. 2시간 설정은 20:00~20:55만 사용합니다.
- 월 0시간이면 연장 퇴근을 배정하지 않습니다.
- 하루 2시간이면 월 시간은 짝수여야 하며, 해당 월 근무일보다 많은 일수를 배정할 수 없습니다.
- 월 시간은 일수 배정 기준입니다. 사이트의 실제 시간 합계와 정확히 같지는 않습니다.
- 생성된 당월 계획과 날짜별 시간은 유지합니다. 이후 설정 변경은 다음 달 새 계획부터 적용합니다.
- 기존 버전의 월 10일 계획도 유지되며 과거 시간을 다시 추첨하지 않습니다.
- 월중 설치나 출근하지 않은 날이 있으면 실제 연장 등록일 수는 배정 일수보다 적을 수 있습니다.

Windows 로그인 시 실행
- PC를 켜고 해당 Windows 사용자로 로그인하면 약 30초 뒤 출근을 처리합니다.
- 오늘 퇴근이 이미 완료되었으면 출근을 다시 처리하지 않습니다.
- 09:00 이후 출근으로 기록된 경우 오늘 출근을 08:30~08:50 중 5분 단위로 보정합니다.
- 이미 09:00 이전 출근 기록이 있으면 유지합니다. 보정 시간은 날짜별로 저장합니다.
- 근태관리에서 이전 근무일의 출근 기록이 있고 퇴근만 빈 경우 보완합니다.
- 다음 날이 휴일/주말이면 그 다음 출근 때 이전 근무일을 확인합니다.
- 이전 버전에서 알려지지 않은 오래된 누락분 전체를 일괄 수정하지는 않습니다.
- 이 버전에서 보류된 날짜 및 로컬 출근 성공/퇴근 미완료 날짜는 함께 재확인합니다.
- 이미 퇴근이 있는 날, 출근이 없는 날, 주말·공휴일은 퇴근 시간을 추가/변경하지 않습니다.
- 보완에는 그날 저장된 동일한 일반/연장 퇴근 시간을 사용합니다.
- 대상 외 출근/퇴근/비고 입력값은 유지하고 저장 후 표의 반영 결과를 재확인합니다.
- 연도 선택을 확인할 수 없는 전년도 기록은 자동 수정하지 않고 보류합니다.
- 보정·보완 실패와 확인된 오늘 출근 성공은 별도로 취급합니다.

설치 및 적용 (자동으로 설치되지 않습니다)
1. 근태매니저_설치.exe 파일 하나를 실행합니다. 사용자 압축 해제는 필요 없습니다.
2. Google Chrome이 설치되어 있는지 확인합니다.
3. 설치가 끝나면 근태매니저 화면이 자동으로 열립니다.
4. ID/PW, 월 연장시간, 하루 기준을 선택합니다.
5. ID/PW 저장 및 작업 등록을 누릅니다.
- 기존 계정과 실행 기록이 있으면 유지됩니다. 기존 PW를 유지하려면 빈칸으로 둡니다.
- 등록 작업: 자동출근 / 자동퇴근 / 자동출퇴근로그인.
- 설치 위치: %LOCALAPPDATA%\AutoAttendance.
- 계정 정보는 설치 PC에 저장되며 배포 ZIP에 포함되지 않습니다.
- 설치와 예약 작업 등록은 사용자가 위 단계를 실행할 때만 이루어집니다.

관리 및 오류 확인
- 출퇴근관리.bat에서 설정 변경, 일시 정지, 다시 시작, 완전 삭제가 가능합니다.
- 일시 정지는 로그인 작업과 기존 예약 작업을 모두 정지합니다.
- 브라우저 도중 강제 종료되거나 결과가 불명확하면 당일 작업을 무조건 재전송하지 않습니다.
- 이 경우 사이트 실제 기록과 아래 로그를 확인해 주세요.
- 로그: %LOCALAPPDATA%\AutoAttendance\dist\자동출퇴근.log.

Python 및 Windows 보안
- Python을 별도로 설치하거나 PATH를 설정할 필요가 없습니다.
- 공식 CPython 3.12.10 포터블 런타임을 패키지에 포함했습니다.
- 설치 시 Python Software Foundation 전자서명과 패키지 파일 SHA-256을 검사합니다.
- 새로 패킹한 PyInstaller EXE 대신 공식 런타임과 읽을 수 있는 소스를 사용합니다.
- 커스텀 설치 스크립트와 Python 소스 자체에 공인 코드 서명이 있는 것은 아닙니다.
- SHA-256 목록은 손상 여부 확인용이며, 제작자 공인 서명을 대신하지 않습니다.
- Defender/SmartScreen/회사 정책 또는 향후 Windows 업데이트에 의한 차단을 100% 방지할 수는 없습니다.
- 설치 프로그램은 Defender 예외나 백신 해제, Windows 업데이트 해제를 설정하지 않습니다.
- 차단되면 정확한 탐지명/오류 내용을 확인하여 정상 파일 오탐 여부를 판단해야 합니다.

r10 단일 설치 EXE / 시간외근무 / 감시 기능
- 근태매니저_설치.exe 하나만 실행하면 설치와 프로그램 실행이 이어집니다.
- 첫 화면에서 자동 출퇴근 등록 설정 또는 시간외근무 신청을 선택합니다.
- 시간외근무 신청은 당월이 기본입니다. 다른 월을 선택하면 그 월의 실제 연장 퇴근 기록으로 신청합니다.
- 날짜별 근무목적을 직접 입력하고 확인한 항목만 신청합니다. 부서는 센터, 시작은 18:00, 종료는 19:00/20:00이며 아래 날짜도 근무일과 같습니다.
- 관리 창을 닫는 것은 백그라운드 종료가 아닙니다. 의도적 종료는 자동 실행 종료 또는 일시 정지를 누릅니다.
- 별도 EXE 감시가 비정상 종료·응답/작업 중단을 감지합니다. 15분 내 3회 실패 시 재시작을 중단하고 알립니다.
- 실행 상태 화면은 프로세스 응답 / 사이트 연결 / 실제 로그인 확인을 구분합니다.
- 보안 안내에서 Windows 보안을 열고 설치 경로를 복사할 수 있습니다. 보안 설정은 임의 변경하지 않습니다.
- 자동 업데이트는 공개 저장소 attendance-manager-updates에 연결되어 실행 시 새 버전을 확인합니다. 코드 업데이트는 약 53KB이며 전자서명과 해시 검증 후 적용합니다.
- 자세한 구조, 변경 파일, 설정, 모의시험과 실제 재부팅 시험 절차는 개발변경_설정_시험안내.md를 참고하세요.

- 성명·직위를 입력하고 센터 출장 엑셀 내보내기를 누르면 선택 월의 실제 등록된 센터 출장만 첨부 양식으로 저장합니다. 협회는 제외합니다.

[v53 출장 최종 정리]

삭제 예정 건의 시간·금액은 합계에서 빠집니다. 다시 누르면 삭제 취소됩니다.

프로그램에서 최종 확인한 뒤 해당 행의 실제 삭제 링크를 한 번 실행하고, 사이트 목록에서 삭제가 확인된 기록만 완료 처리합니다.
직위는 기본 빈칸이며 직접 작성할 수 있습니다.

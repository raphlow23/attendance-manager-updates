원격 설치 PC에서 출근 예정 09:00을 입력한 뒤 08:50이 다시 읽히는 오류가 보고되었습니다. 시간 입력을 키보드 포커스에 의존하지 않도록 보완했습니다. 확인된 시간 입력칸 두 개에 브라우저의 표준 value setter로 시/분을 먼저 반영하고 input/change 및 focus/blur 이벤트를 전달합니다. 편집 불가 또는 읽기 전용 칸은 변경하지 않습니다.

검증은 HTML 초기 value 속성이 아닌 현재 입력 상태인 get_property(value)를 사용합니다. 비고와 다른 입력값 보존 검사도 현재 값 기준으로 수행합니다. 값이 실제로 맞지 않거나 사이트가 되돌리면 저장을 멈추며, 수정 대상/기록 번호/월/사이트 및 최종 저장 확인은 유지합니다. 값 불일치를 무시하거나 서버에 직접 POST하는 방식이 아닙니다.

135개 자동 검사 통과. 실제 Chrome156의 로컬 HTML에서 키보드 입력을 무시하고 value 속성은 초기 값만 돌려주는 조건을 만들어, 목록 이동/수정 폼 탐색/현재 값 설정/공백 정규화/저장 모의/재확인을 통과했습니다. 초기 속성 08과 현재 값 09가 달라도 실제 현재 값으로 저장·검증하는 회귀 검사를 추가했습니다. 일반 입력표 경로도 실제 Chrome에서 통과했습니다.

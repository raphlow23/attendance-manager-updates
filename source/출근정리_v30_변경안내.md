출근정리 v30

선택 날짜는 한 날짜 수정 화면 열기 → 해당 날짜 입력 → 수정완료 활성화 → 저장 값 확인 → 다음 날짜 순으로 처리합니다. 기존 루프도 날짜별이었으며 이번에는 수정완료 버튼을 좌표 기반 WebDriver 클릭에 의존하지 않고 브라우저 DOM의 버튼 활성화로 한 번만 실행하도록 보완했습니다. 표준 폼 검증과 연결된 폼 검사를 유지하며 서버 저장 주소를 직접 호출하거나 여러 날짜를 한 요청으로 보내지 않습니다. 결과 불확실 시 다음 날짜로 넘어가거나 재제출하지 않습니다.

저장 요청이 실제 브라우저 POST로 관측됐는지, 저장 응답 상태와 리다이렉트 및 사이트 알림을 기록합니다. 입력값·POST 본문·쿠키·토큰은 이 진단에 저장하지 않습니다. 사이트의 응답 뒤 목록 확인이 필요하면 관측한 근태 목록 주소로 한 번만 이동합니다. 저장 요청 전에 목록으로 이동해 요청을 취소하지 않습니다.

작업 로그에 날짜별 시작과 저장 확인을 남기고 화면에는 하루씩 처리 중임을 표시합니다. 시간 입력/다른 필드 및 비고 보존/선택 기록 번호·월·사이트 검사는 유지합니다.

검증: 자동 검사 136건. 실제 Chrome156과 로컬 HTTP 서버에서 두 날짜를 실제 폼 POST로 한 번씩 제출하고 새 목록 값을 확인한 뒤 다음 날짜를 처리하는 시험을 통과했습니다. 303 리다이렉트와 저장 후 JavaScript 알림/리다이렉트, 비고 유지, 키보드와 WebDriver 클릭 무시 조건, 초기 HTML 값이 남아 있는 조건을 포함합니다. 실제 대상 사이트에는 접속하거나 저장하지 않았습니다.

적용: 설치 PC의 모든 프로그램 창을 닫고 다시 실행하여 v30 확인 후 수정 목록을 새로 조회하고 선택 내역 정리를 실행하세요.

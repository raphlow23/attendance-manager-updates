선택 내역 정리가 성공하면 정리 완료 알림을 표시하고 하단에 완료 문구를 유지합니다. 행별 상태는 저장 확인 완료 또는 기존 시간 일치로 표시합니다. 개별 저장 후 월을 최종 조회해 선택한 시간과 비고가 일치해야 전체 완료로 표시합니다.

수정 입력창 탐색이 th 제목만 허용하던 부분을 보완하여 td와 혼합 제목도 동일한 네 칸의 의미를 확인한 뒤 허용합니다. 입력창을 무작정 추측하거나 저장 확인을 생략하지 않습니다.

실패 시 Message:만 표시하던 경우를 보완하여 날짜와 단계(로그인/수정 화면 찾기/입력/저장/저장 결과 확인)를 표시합니다. 저장 요청 전후를 구분하며, 일부 날짜만 저장된 경우 확인된 날짜·실패 날짜·미처리 날짜를 구분합니다. 실패 후에는 재조회해야 하며 자동 재시도하지 않습니다.

Python 자동 검사 124건, 수정 창 td/혼합 제목 모의시험, 입력창 및 저장 결과 시간 초과, 일부 저장과 최종 월 조회 불일치 검사, WinForms 완료/실패 행 표시 검사를 통과했습니다. 실제 사이트 계정으로 접속하거나 기록을 저장한 시험은 하지 않았습니다. 로컬 실제 Chrome 시험은 설치 브라우저 156/포함 드라이버 153 불일치로 완료하지 못했습니다. 제품은 기존과 같이 호환 드라이버 자동 확보 경로를 유지합니다.

업데이트 후에도 오류가 나면 화면에 표시된 날짜와 실패 단계를 확인해 주세요. 현재 설치 PC의 오류 로그와 실제 수정 화면 DOM을 이 환경에서 확인하지 못하여 이번 실패 원인을 단정하지 않습니다.

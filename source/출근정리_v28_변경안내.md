출근정리 v28

시간 입력: clear 후 문자열을 즉시 비교하던 방식을 바꿨습니다. 입력칸을 클릭하고 Ctrl+A, Backspace로 교체한 뒤 Tab으로 포커스를 이동합니다. 최대 3초 동안 시/분을 실제 시간 값으로 비교하므로 공백이나 앞자리 0의 표시 차이로 실패하지 않습니다. 실제 값이 다르면 예정 시각과 입력칸의 숫자를 표시하며 저장하지 않습니다. 비고·다른 필드 보존 및 서버 값 확인 절차는 유지합니다. 사용 PC에서 이전 입력 불일치의 정확한 원래 값은 기록되지 않아 확정하지 않습니다.

ChromeDriver: Chrome과 포함 드라이버의 주 버전을 시작 전에 비교하고 알려진 불일치는 건너뛰어 호환 드라이버 캐시/자동 확보 경로를 사용합니다. 신규 설치 EXE는 공식 ChromeDriver 156.0.8078.47과 해당 라이선스를 포함합니다. 기존 설치본의 코드 업데이트는 드라이버를 포함하지 않으며 호환 캐시/확보 경로를 사용합니다. 보안 설정을 바꾸지 않습니다.

감시 프로세스: 상태 JSON 파일이 다른 프로세스에 잠겨 있을 때 원래 v27이 IOException으로 종료되는 상황을 재현했습니다. 고유 임시 파일과 제한된 재시도를 사용하며 상태 저장의 일시적 파일 잠금이 작업 프로세스 종료로 이어지지 않게 했습니다. 실패는 guardian.log에 status write deferred로 남기고 다음 상태 기록에서 다시 저장합니다. 사용자 중지와 업데이트 일시 중지는 계속 존중합니다.

검증: 자동 검사 134건 통과. 실제 Windows 파일 핸들로 상태 파일 교체를 막는 시험에서 새 감시/작업 프로세스가 유지되고 잠금 해제 후 기록이 재개됨을 확인했습니다. v27은 같은 잠금 조건에서 guardian fatal IOException으로 종료되는 것을 별도로 재현했습니다. 호환되는 공식 드라이버와 실제 Chrome 156에서 로컬 일반 입력표 및 첨부 HTML 기반 수정 폼의 목록 이동/키보드 입력/blur 공백 정규화/저장 모의/재확인을 통과했습니다. 실제 대상 사이트에는 접속하거나 기록을 저장하지 않았습니다.

적용: 설치 PC에서 모든 프로그램 창을 닫고 다시 실행해 v28 적용을 확인합니다. 목록을 새로 조회하고 선택 내역 정리를 실행하세요.

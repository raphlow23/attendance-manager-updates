출근정리 v31 — 4번 출장일지 및 시간외근무 신청 연결 보완

4번 메뉴 출장일지를 추가했습니다. 목표 금액과 월을 고르고 출퇴근 일정 조회를 누르면 출근/퇴근이 모두 등록된 날짜를 표시합니다. 연장 제외일은 이 대상 중 필수 선택이며 09:00~18:00, 인정 4시간/2만원으로 고정합니다. 일반 출장은 2시간 1만원 또는 4시간 2만원입니다. 정상 출장의 출발 시를 선택하면 복귀 시를 계산하며 출퇴근 구간을 벗어나면 등록하지 않습니다. 구분 센터/이동수단 대중교통을 고정합니다.

1단계는 전체 일정에서 날짜와 시간을 선택합니다. 금액이 차면 추가 체크를 거절하고, 1만원이 남으면 2시간으로 맞춥니다. 시간을 줄이거나 체크를 해제하면 다시 선택할 수 있습니다. 선택일 시간 배분은 사용자가 선택한 날짜 안에서만 2/4시간을 배분합니다. 부족하면 출장 추가 필요 시간과 금액을 표시합니다. 선택 완료는 목표 금액·인정시간이 맞아야 가능합니다.

2단계는 선택한 날짜만 표시해 출장 장소와 목적을 직접 입력합니다. 일정 다시 선택으로 돌아가도 내용을 유지합니다. 선택 날짜 순서대로 등록을 누르면 실제 페이지의 등록 폼을 한 날짜씩 채우고 확인 버튼을 눌러 저장을 확인한 뒤 다음 날짜로 진행합니다. 기존 월 출장도 목표 금액에 포함하고 날짜별 인정시간을 최대 4시간으로 계산합니다. 이미 등록된 날짜는 중복 제외합니다. 기존 제외일 출장 시간이 09~18시와 다르면 자동 중복 등록 대신 확인 필요로 표시합니다.

조회 후 계정·달력·출퇴근·기존 출장 내역이 바뀌면 재조회해야 합니다. 한 번 등록한 조회 목록은 재사용하지 않습니다. 저장 결과가 불확실하면 중단하고 다음 날짜를 처리하지 않습니다. 조회/등록은 버튼을 누를 때만 사이트에 접속하며 금액 계산과 날짜/시간 선택은 사이트 요청을 만들지 않습니다. 현재 사이트의 과거 연도 선택이 확인되지 않아 출장 조회는 당해 연도만 지원합니다.

시간외근무 신청: 근무일지와 시간외근무신청 링크를 실제 DOM에서 읽어 이동하도록 보완했습니다. 신청서의 센터·날짜·요일·시간·목적을 현재 값으로 채우고 신청 버튼을 한 번 활성화하여 저장 확인 후 다음 날짜를 처리합니다.

검증: 자동 검사 150건, 실제 WinForms 출장 2단계 선택·금액 차단·시간 변경·내용 보존 및 4개 메뉴 화면 검사, 실제 기능 창 호스트 6개 반복 실행 통과. 실제 Chrome156과 로컬 HTTP 서버에서 출장 2일과 시간외근무 2일을 순서대로 POST 저장하고 금액/비고/중복 방지/중첩 메뉴 바로가기를 확인했습니다. WebDriver 키보드와 좌표 클릭을 무시하는 조건에서도 통과했습니다. 실제 대상 사이트의 출장/신청 HTML 원본은 아직 제공되지 않아 화면 사진에 따른 의미 기반 탐색을 사용합니다. 실제 서버 접속·저장은 실행하지 않았으며 최신 DOM과 저장 결과 실기 확인은 설치 PC에서 필요합니다.

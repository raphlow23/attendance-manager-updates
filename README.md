# 근태매니저 업데이트 배포

Windows용 근태매니저의 공개 업데이트 저장소입니다.

## 기능

- 근태 자동관리와 시간외근무 신청 기능 선택
- Windows 사용자 로그인 시 자동 시작
- 별도 EXE 감시, 응답·사이트 연결·실제 로그인 결과 구분
- 비정상 종료 복구, 중복 실행 방지, 사용자 의도적 종료 존중
- 월별 실제 연장 퇴근 조회 및 직접 입력한 근무목적으로 신청
- RSA 서명과 SHA-256을 확인하는 실행 시 자동 업데이트

## 설치와 업데이트

초기 설치에는 별도로 제공되는 **근태매니저 설치패키지 ZIP**을 완전히 압축 해제한 뒤 `설치.exe`를 실행하세요. Python을 별도로 설치할 필요가 없습니다.

이 저장소의 `updates/v9/attendance-manager-v9.zip`은 **기존 설치본용 코드 업데이트**입니다. Python 런타임을 포함하지 않으므로 단독 설치본이 아닙니다.

프로그램에 설정된 업데이트 주소:

```text
https://raw.githubusercontent.com/raphlow23/attendance-manager-updates/main/updates/latest.json
```

현재 배포 버전: **9 (2026-10-26)**. 업데이트 ZIP은 약 53KB이며, 포함된 공식 Python 런타임은 코드 업데이트로 교체하지 않습니다.

## 사용

1. 근태 자동관리 설정에서 계정과 월 연장시간을 저장하고 작업을 등록합니다.
2. 화면을 닫아도 백그라운드는 유지됩니다. 의도적으로 중지할 때는 **자동 실행 종료**를 선택합니다.
3. 시간외근무 신청은 당월 기본값에서 조회 월을 변경할 수 있습니다. 실제 19시대/20시대 퇴근을 각각 18:00~19:00/20:00 신청으로 표시합니다. 날짜별 목적을 직접 입력하고 확인한 항목만 신청합니다.
4. 실행 상태와 보안 안내에서 오류 원인 및 Windows 보안 보호 기록을 확인할 수 있습니다.

## 검증 및 한계

오프라인·격리 프로세스·로컬 연결 장애 모의시험을 수행했습니다. 실제 Windows 재부팅과 출퇴근 사이트의 로그인·수정·시간외 신청 저장은 별도 통합시험이 필요합니다.

Defender, SmartScreen, 방화벽 또는 Windows 업데이트를 무력화하거나 예외를 자동 추가하지 않습니다. 자체 EXE의 공인 코드 서명은 없으므로 특정 보안 정책에서 실행 경고나 차단이 생길 수 있습니다. 업데이트용 RSA 서명은 Windows 공인 코드 서명과 다릅니다.

계정정보, 실행 기록, 사용자 설정과 업데이트 서명 개인키는 이 저장소에 포함하지 않습니다.

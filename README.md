# 근태매니저

Windows용 근태 자동관리 및 월별 시간외근무 신청 프로그램의 업데이트 저장소입니다.

## 설치

[**설치 EXE 바로 다운로드 — AttendanceManager_Setup.exe**](https://github.com/raphlow23/attendance-manager-updates/releases/download/v13/AttendanceManager_Setup.exe)

다운로드한 **AttendanceManager_Setup.exe 파일 하나**를 실행하면 필요한 파일을 자동으로 풀고 현재 사용자 프로그램 폴더에 설치한 뒤 관리 화면을 바로 엽니다. 별도 Python 설치나 수동 ZIP 압축 해제는 필요하지 않습니다.

Windows 설정의 **설치된 앱** 또는 제어판의 프로그램 제거에서 **근태매니저**를 제거할 수 있습니다. 제거 시 자동 실행/감시/자식 프로세스, 예약 작업 4개, 바로가기, 프로그램·계정·기록과 앱 등록 정보를 정리합니다.

이 저장소의 ZIP은 **기존 설치본용 코드 업데이트**입니다. Python 런타임을 포함한 초기 설치 EXE와는 별도입니다.

초기 설치 EXE는 기존 v13 설치 파일이며, 설치 후 프로그램 실행 시 최신 v16이 자동 적용됩니다. 현재 GitHub의 새 EXE 첨부가 전송 오류로 실패하여 검증된 기존 설치 링크를 제공합니다.

## 자동 업데이트

버전: **16 (2026-10-27)**

고정 주소:

https://raw.githubusercontent.com/raphlow23/attendance-manager-updates/main/updates/latest.json

실행할 때 최신 버전을 확인하며 RSA 서명과 SHA-256이 맞는 코드 업데이트만 적용합니다. 사용자 계정·기록은 보존합니다. 공인 Windows 코드 서명과는 다른 서명입니다.

## 기능

- 근태 자동관리 / 시간외근무 신청 선택
- 로그인 시 자동 시작, 별도 EXE 감시와 제한된 자동 재실행
- 의도적 중지 존중, 중복 실행 방지, 실제 로그인 결과 및 오류 로그
- 당월 기본 및 월 선택으로 실제 연장 퇴근 조회, 날짜별 직접 입력 목적
- 센터 부서, 18:00 시작, 실제 퇴근의 분을 제외한 19:00 또는 20:00 종료
- Windows 보안 진단 안내. 보안 기능·방화벽·업데이트·제외 규칙을 임의 변경하지 않음

실제 출퇴근 사이트 로그인·수정·신청 저장, Windows 재부팅과 실제 제어판 제거는 별도 실기 시험이 필요합니다. 자체 EXE의 공인 코드 서명이 없어 보안 정책에 따라 경고나 차단이 발생할 수 있습니다.

계정정보·실행 기록·서명 개인키는 공개하지 않습니다.

## v11 설치 수정

Windows PowerShell에서 설치 종료 코드가 비어 정상 설치를 실패로 표시하던 문제를 수정했습니다. 설치 실패 시 원인과 종료 코드를 표시하고 `%TEMP%\AttendanceManager-install-logs`에 로그를 보존합니다. 단일 EXE 내부의 GUI 설치 경로를 별도 시험 폴더에서 검증했습니다.

## v12 변경

- 설정 저장 및 시간외근무 조회 시 `Replace` 경로 오류 수정
- 메뉴에서 연 설정 창이 메뉴 앞에 표시되도록 소유 창 지정
- 출근·일반 퇴근 시작/종료 시간 및 1분/5분 간격 설정 추가
- 조회 월 드롭다운(최근 60개월), 새 월 자동 추가 및 선택한 월 유지
- 자동 업데이트 설정 버튼 제거: 실행 시 고정 배포 주소에서 서명을 검사하고 자동 적용
- 실행 파일·프로그램 창·설치 파일에 시계와 체크 표시 아이콘 적용

이미 만든 당일 예약 시각은 보존하며 시간 범위 변경은 새 예약부터 적용합니다. PC 로그인 시 즉시 출근하는 기존 동작을 유지합니다. 연장일에는 1시간 기준 19:00–19:55, 2시간 기준 19:00–20:55에서 선택한 분 간격을 적용합니다. 월 선택 목록은 프로그램을 실행할 때와 켜 둔 상태에서 달이 바뀔 때 갱신됩니다.

검증: Python 테스트 60개, Windows PowerShell 기존 파일 교체, 별도 프로세스 설정 창 소유 관계·메뉴 복귀, 월/연도 전환, v11→v12 서명 업데이트·사용자 데이터 보존, 단일 EXE 설치 시험 및 Defender 파일 검사 통과. 실제 사이트 등록·신청은 별도 실기 검증이 필요합니다.

## v13 변경

- 작업 표시줄이 PowerShell로 묶이지 않도록 근태매니저 전용 AppUserModelID를 지정했습니다.
- 실행 시 메뉴를 먼저 표시하고 업데이트 확인을 백그라운드에서 수행합니다.
- 새 버전이 있으면 설정 창을 닫은 뒤 자동 적용하고 메뉴를 다시 엽니다. 적용 중에는 조작과 종료를 잠시 막아 파일 교체를 보호합니다.
- 창 관련 보조 코드를 EXE에 미리 컴파일해 매번 동적 컴파일하던 시간을 줄였습니다. EXE는 메모리에서 로드해 업데이트 파일 교체를 방해하지 않습니다.

검증: 전용 작업 표시줄 앱 ID 조회, 별도 프로세스 창 소유 관계, 4초 업데이트 지연 중 UI 타이머 응답, 서명/무결성 검사, v11 업데이트 호환 및 사용자 데이터 보존 시험 통과. 실제 사용자 PC의 고정 아이콘/캐시 반영 여부는 별도 확인이 필요합니다.

## v15 메뉴·속도 개선

- 메인 메뉴의 자동 실행 시작/종료 버튼 제거. 근태 자동관리 설정의 일시 정지/다시 시작으로 예약 작업 4개와 상주 실행을 함께 제어합니다.
- 보안 안내와 실행 상태 버튼을 한 줄에 배치했습니다.
- 메뉴마다 PowerShell 프로세스를 새로 만드는 대신 준비해 둔 STA 실행 환경을 재사용하고 화면을 미리 준비합니다.
- 예약 상태 조회, 설정 저장·등록, 정지·재개를 백그라운드에서 처리하고 진행 상태를 표시합니다.
- 예약 등록 4건을 한 PowerShell 호출로 묶었습니다.
- 예약 점검은 콘솔 없는 EXE를 거쳐 실행합니다. 기존 점검 예약도 정지 상태를 보존하면서 자동 전환합니다.
- Python 작업, ChromeDriver, 드라이버 버전 확인에서 새 콘솔 생성을 막았습니다. Windows 보안 설정은 바꾸지 않습니다.

검증: Python 62개 테스트, 실제 창을 같은 프로세스에서 반복 표시, 정지·재개 및 실패 시 정지 유지(예약 도구 모의), 점검 예약 전환 시 비활성 상태 보존, 실제 콘솔 핸들 0 확인, 기존 설치본 서명 업데이트 호환 통과. 시험에서 설정 재표시 약 0.23초, 준비된 조회/상태/안내 창 약 0.08~0.21초였으며 첫 준비와 사용자 PC 사양·보안 검사·웹사이트 응답에 따라 달라집니다.

처리된 오류 기록이 남아 있어도 정상 결과를 실행 실패로 표시하지 않도록 추가 보완했습니다. 실제 창 반복 표시 및 정상적으로 처리한 오류가 있는 창의 반복 실행 회귀 시험도 통과했습니다.

## v16 휴가·제외일과 실제 근태 정정

- 두 번째 메뉴에 휴가·연장 제외일 및 근태 정정을 추가했습니다. 시간외근무 신청은 세 번째 메뉴입니다.
- 휴가일은 자동 출퇴근과 누락 보완을 건너뛰고, 연장 제외일은 미완료 연장 예약을 일반 퇴근으로 바꿉니다. 제외 체크를 풀고 저장하면 해제합니다.
- 기존 사이트 기록은 제외 설정만으로 변경하지 않습니다. 월 조회 후 날짜를 선택해 실제 출퇴근 시간과 사유를 입력하고 변경 전후를 확인해야 저장합니다. 비고를 유지하며, 빈 입력칸은 기존 시간을 유지합니다.
- 월 연장 일수를 채우기 위해 다른 날짜를 자동 변경하지 않습니다. 휴가 자체는 사이트의 휴가 처리 규정에 따릅니다.
- 저장 결과가 불확실하면 해당 날짜 자동 처리를 보류합니다. 사이트 확인 후 다시 조회하여 실제 기록으로 정정하면 해제합니다. 프로그램에서 기존 시간외 신청 완료/결과 불확실로 기록한 날짜는 정정을 차단합니다.
- 정정 후 시간외근무 신청에서 월을 다시 조회하면 서버의 변경된 퇴근 기록을 기준으로 신청합니다.

검증: Python 69개 테스트, 기존 기록·비고 보존과 변경 충돌 방지, 제외일 반영, 불확실한 저장 후 자동 처리 보류, 실제 WinForms 화면 실행, v11 업데이트 서명 호환과 데이터 보존, 단일 EXE 별도 폴더 설치 시험 통과. 실제 사이트 저장은 수행하지 않았습니다.

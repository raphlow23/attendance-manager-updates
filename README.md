# 출근정리

Windows용 출퇴근 자동관리, 근태 정리, 시간외근무 및 출장일지 프로그램입니다.

## 설치

[초기 설치 EXE 다운로드](https://github.com/raphlow23/attendance-manager-updates/releases/download/v13/AttendanceManager_Setup.exe)

현재 초기 설치 EXE는 v13 부트스트랩입니다. 설치 후 프로그램 실행 시 **최신 1.5.8**를 자동으로 받습니다. 최신 단일 설치 EXE는 로컬에서 빌드·검증했으나 GitHub 웹 첨부가 `storage request` 오류로 실패하여, 첫 설치 경로를 유지하기 위해 이 파일을 임시 보존합니다. 새 EXE로 대체하기 전에는 위 파일을 삭제하지 마세요.

## 자동 업데이트

- 현재 버전: **1.5.8**
- [업데이트 정보](https://raw.githubusercontent.com/raphlow23/attendance-manager-updates/main/updates/latest.json)
- [현재 업데이트 ZIP](https://raw.githubusercontent.com/raphlow23/attendance-manager-updates/main/updates/v58/attendance-manager-v58.zip)

ZIP은 기존 설치본용이며 설치 EXE가 아닙니다. 실행 시 RSA 서명과 SHA-256을 확인하고 업데이트하며 사용자 설정과 기록은 보존합니다. Windows 보안 설정을 임의로 변경하지 않습니다.

## 현재 기능

- Windows 로그인 시 자동 출퇴근 처리와 상태·오류 기록
- 휴가/행사 제외일 설정과 선택한 월의 근태 정리
- 월별 시간외근무 신청 및 기존 신청 수정
- 출장 기등록 표시·금액 합산·기존 출발·복귀 시간과 장소·목적 수정
- 목표 미달 일정도 안내 확인 후 진행, 제외 내역 확인 후 등록
- 장소 → 목적 → 다음 행 장소 순서로 Tab/Enter 이동, Shift 역방향

[현재 버전 변경 안내](./출근정리_v58_변경안내.md)

- 출발 시·분과 복귀 시간 직접 수정, 장소·목적 한 번 클릭 입력
- 선택 칸 전체를 한 번 클릭하여 체크/해제

- 체크박스 편집 버퍼 제거: 선택·해제 및 합계 즉시 반영
- 실제 출장 수정 표 머리글과 입력칸을 연결하여 기존 건 수정

- 출장 수정 화면의 저장된 시간 옵션 중복을 구분하고 선택 후 값 재확인

- 중복인 기존 출장 불러오기·수정 버튼 제거. 일정 조회 → 날짜 선택 → 선택 완료·기존 출장 확인으로 통일

- 일반 퇴근은 18:05부터, 하루 2시간 연장 퇴근은 20:00~20:55
- 시간외근무 선택 건이 모두 저장 확인되면 작업창 자동 닫기. 출장은 완료 안내 후 첫 화면을 유지하여 센터 출장 엑셀 내보내기 가능. 부분 처리·실패는 완료로 표시하지 않습니다.
- [PDF 사용설명서](./docs/attendance-manager-manual-v49.pdf)

- 출장 구분: 센터·협회 드롭다운, 신규 기본 센터
- 센터 출장 엑셀 내보내기: 내장 빈 양식 사용. 조회 월·성명·직위 입력 후 실제 등록된 센터만 포함, 협회 제외. 원본 양식 선택 불필요.
- 원본의 개인정보·출장 내역·지급액·작성 이력·PC 경로·프린터 기기 정보를 제거한 빈 양식만 내장합니다. 개인별 보고서는 PC에만 저장합니다.
- 파일명 예: `2026 출장비지급내역(10월)_.xlsx` (성명은 문서 안에만 표시)
- 19건 초과 시 동일 양식의 추가 시트, 각 시트별 횟수·지급액 계산
- 기본 PDF는 v49 기준이며 1.5.8 기능은 현재 변경 안내를 참조하세요.

- [개인정보 제거한 빈 양식 다운로드](./templates/trip-expenses-blank.xlsx)

- 출장 가능 날짜 조회 결과의 기등록 행 바로 옆에 삭제 버튼 제공
- 삭제 버튼은 삭제 예정만 표시하며 사이트에 접속하지 않습니다. 삭제 예정 금액·시간은 합계에서 빠지고 삭제 취소로 되돌릴 수 있습니다.
- 마지막 선택 내역 정리에서 삭제·등록·수정을 하나의 연결로 순차 처리하고 사이트 목록에서 부재를 확인합니다.
- 삭제 후 장소·목적·가능한 시간은 재등록 초안으로 유지. 결과 불확실 또는 대상 변경 시 재조회 안내.

## 배포 자료 정리

사용자의 요청으로 기본 브랜치에서 v9~v43 업데이트 ZIP 35개, 오래된 중복 source 폴더 68개 파일, 이전 변경 안내 12개를 제거했습니다. 최신 1.5.8 업데이트와 필요한 현재 파일을 유지합니다. Git 커밋 이력 자체는 재작성하지 않았으므로 과거 이력에는 이전 자료가 남을 수 있습니다.

실제 사용자 PC 사이트는 직접 시험하지 않았습니다. 공인 Windows 코드 서명은 없으며 RSA 업데이트 서명과는 별개입니다. 계정정보·실행 기록·서명 개인키는 배포하지 않습니다.

추가 정리: 이전 릴리스 v10·v11·v12·v15 및 빈 초안 2개를 삭제하고 태그 v10·v11·v12·v15도 제거했습니다. 첫 설치를 위해 v13 릴리스·태그와 설치 EXE 한 개만 보존합니다. 프로그램 최신 코드는 1.5.8입니다.

- 직위는 기본 빈칸이며 직접 입력한 값으로 엑셀에 저장합니다.

- 프로그램의 최종 정리 확인 후 해당 행에서 실제로 읽은 삭제 링크를 한 번 실행합니다. 첨부 HTML에서 확인한 단순 확인 후 링크 이동 구조만 지원하며, 사이트 목록에서 삭제 결과를 검증합니다.

- 다음 단계 버튼: 출장 수정 및 작성. 다음 작성 화면에서는 금액 열을 숨깁니다.

- 출장 수정·등록 완료 안내 후 첫 화면을 유지합니다. 창닫기로 직접 종료할 수 있습니다.

- 사용자용 버전 표시는 1.5.8이며 자동 업데이트 내부 순번은 유지합니다.

- 출장 목표금액·인정시간 및 선택 제한은 센터만 계산합니다. 협회 기록은 목록에 표시하지만 합계에서는 제외하며, 구분 변경·삭제 예정도 센터 기준으로 반영합니다.
